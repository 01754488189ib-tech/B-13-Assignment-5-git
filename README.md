
1️⃣ What is the difference between var, let, and const?

Var: This is an old method; it can be redeclared multiple times with the same name and the value can be changed.

Let: This is a modern method; the value can be changed but it cannot be redeclared with the same name within the same block.

Const: This is for permanent values once assigned the value cannot be changed.

2️⃣ What is the spread operator (...)?

It is a simple way to extract all the data from a list or object at once and copy or join it elsewhere.

3️⃣ What is the difference between map(), filter(), and forEach()?

For-each: Only works on each element of the list returns nothing.

Map: Works on each element and returns a new list of equal length.

Filter: Returns a new smaller list containing elements that meet the conditions.

4️⃣ What is an arrow function?

It is a modern and concise way of writing functions where an arrow-like symbol => is used.

5️⃣ What are template literals?

This is a method of displaying text using backticks [``] which allows variables or values to be easily inserted within it.
